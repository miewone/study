IDENTITY RULE

이름 ≠ identity

Amazon은 검색용 title일 뿐입니다. 최종 identity는 국가에 종속된 deterministic UUID입니다.

1. Object Type 검색 — Market, Retailer를 visible catalog에서 찾습니다.
2. Instance 검색 — CA는 1개, Amazon은 CA/DE/UK 3개를 반환합니다.
3. Clarification — 이전 후보 snapshot을 참조해 CA Amazon candidate를 선택합니다.
4. Graph 검증 — selected Retailer의 operatesIn target이 selected Market과 같은지 확인합니다.
5. Scope 봉인 — candidate, graph, caller, visibility, version digest를 하나의 immutable Scope로 만듭니다.

04 · trusted scope

07 · trust boundary

무엇이 실제였고, 무엇은 의도적으로 가짜였나

실제로 실행한 것

  • fresh disposable PostgreSQL 16 Registry
  • Registry ACTIVE graph read
  • Object Type·instance resolver
  • CA/Amazon clarification과 Scope 봉인
  • 실제 P0-053 Function integration
  • 실제 summary·contribution·audit Strategy
  • source read 1, publish 1, cleanup retained 0

의도적으로 실행하지 않은 것

  • production endpoint 접근: 0
  • production mutation: 0
  • fallback route: 0
